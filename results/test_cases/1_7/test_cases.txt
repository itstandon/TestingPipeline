Title          : Verify that the glossary displays the definition for “Admin”
Requirement    : Req-1.7-001
Preconditions  : • System is up and reachable  
                 • User is logged in with a role that has read access to the glossary (e.g., Doctor, Patient)  
                 • Glossary module is populated with the definitions listed in Table 1‑Definition

  1. Navigate to the “Glossary” or “Help → Definitions” page.

TC-ID          : TC-1.7-018
Title          : Security – Verify that only authorized roles can edit glossary entries
Requirement    : Req-1.7-018
Preconditions  : • System operational  
                 • Two users exist:  
                   – Admin (role: Admin) with edit rights  
                   – Doctor (role: Doctor) with read‑only rights  
                 • Glossary contains at least one term
Test Steps     :
  1. Log in as Doctor.  
  2. Attempt to access the “Edit” button for any glossary term.  
  3. Observe the UI.  
  4. Log out.  
  5. Log in as Admin.  
  6. Access the “Edit” button for the same term.
Expected Result:  
  – Doctor sees no edit option or receives “Access denied”.  
  – Admin can open the edit form and modify the term.  
Test Type      : Security
