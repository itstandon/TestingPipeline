TC-ID          : TC-2.3-001
Title          : Patient registers successfully with valid data
Requirement    : UC-01
Preconditions  : • System is configured and running  
                 • Registration page is accessible via URL  
                 • No existing patient account with the same email
Test Steps     :
  1. Navigate to the registration page URL.  
  2. Fill all mandatory fields (Name, Email, Password, DOB, Contact, Address) with valid values.  
  3. Click the “Register” button.
Expected Result: Patient account is created, a confirmation message is displayed, and the patient can log in.
Test Type      : Functional
