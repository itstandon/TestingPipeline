Title          : Verify Patient Appointment file generated without full scan of Consultation Request entity
Requirement    : Req-2.5-a
Preconditions  : 
  - Consultation Request table contains at least 10,000 records spanning multiple dates.
  - System index on Appointment Date exists.
  - Derived entity “Patient Appointment file” is configured.
Test Steps     :
  1. Log in as an authorized system user with permission to generate appointment reports.
  2. Request generation of the “Next Day Appointment” report through the UI/API.
  3. Capture the executed database query (e.g., via query logger or profiler).
  4. Verify that the query reads from the Patient Appointment file and not from the raw Consultation Request table.
Expected Result: Report is produced correctly; query plan shows no full table scan of Consultation Request entity (only indexed access on Patient Appointment file).  
Test Type      : Functional
