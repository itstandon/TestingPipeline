TC-ID          : TC-2.7-001
Title          : Register patient residing within the allowed zone
Requirement    : Req-2.7-01
Preconditions  : • System is live and accessible.<br>• List of allowed PinCodes / radius (25 km) is configured.<br>• Patient has a valid address that falls inside the allowed zone.
Test Steps     :
  1. Open the registration page.
  2. Enter patient details including the address inside the allowed zone.
  3. Submit the registration form.
Expected Result: Patient account is created successfully; system displays a confirmation message and sends a welcome email.
Test Type      : Functional

  1. Open “Upload Reports” dialog within the consultation.
