TC-ID          : TC-1.4-001
Title          : Submit a doctor‑visit request within the service zone during normal hours
Requirement    : REQ-1.4-001, REQ-1.4-002, REQ-1.4-006
Preconditions  :
  - Patient is registered and authenticated in the system.
  - Patient’s address is geocoded and lies **inside** the 25 km service zone (e.g., latitude/longitude within zone).
  - System time is within normal operating hours (any time, since service is 24/7).
Test Steps     :
  1. Log in as the patient.
  2. Navigate to “Request Home Doctor Visit”.
  3. Verify that the address auto‑populates correctly.
  4. Click “Submit Request”.
Expected Result: The request is accepted, a confirmation screen displays a request ID, and the system schedules a doctor visit; the request status is “Pending”.  
Test Type      : Functional

TC-ID          : TC-1.4-002

Requirement    : REQ-1.4-006
