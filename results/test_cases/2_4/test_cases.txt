TC-ID          : TC-2.4-001
Title          : Verify system deployment on Heroku platform
Requirement    : Req-2.4-001
Preconditions  :
  - Source code repository is prepared and passes all unit tests
  - Heroku CLI is installed and user is logged in
  - Heroku account has an available app slot
Test Steps     :
  1. Execute `heroku create <app-name>` to create a new Heroku app.
  2. Push the application code to Heroku with `git push heroku main`.
  3. Run `heroku ps:scale web=1` to start the web dyno.
  4. Open the app URL provided by Heroku in a browser.
Expected Result: The application starts without errors, the dyno is running, and the web page loads correctly indicating successful deployment on Heroku.
Test Type      : Functional

TC-ID          : TC-2.4-002
Title          : Verify connection to MySQL Database version 5.7.21
Requirement    : Req-2.4-002
Preconditions  :
  - MySQL server 5.7.21 is installed and running on the configured host
  - Database schema has been applied
  - Application configuration points to this MySQL instance (host, port, user, password)
Test Steps     :
  1. Launch the application (deployed on Heroku) and navigate to a page that queries the database (e.g., login or dashboard).
  2. Observe the application’s ability to retrieve data (e.g., list of patients).
  3. In parallel, connect to the MySQL server using a MySQL client and run `SELECT VERSION();`.
Expected Result: Application displays data correctly, and the MySQL client returns `5.7.21` confirming the correct version is in use.
Test Type      : Functional
