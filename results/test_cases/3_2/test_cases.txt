TC-ID          : TC-3.2-001
Title          : Verify system is deployed on Heroku platform
Requirement    : 3.2 (Deployment on Heroku)
Preconditions  :
  • The Virtual Clinic application has been released to production.
  • Access to the public DNS records for the application is available.
Test Steps     :
  1. Open a web browser on any device.
  2. Perform a DNS lookup for the application’s domain name.
  3. Observe the CNAME or A‑record values returned.
  4. Navigate to the URL returned.
Expected Result: The DNS records resolve to a Heroku‑provided domain (e.g., *.herokuapp.com) and the web page loads successfully, confirming deployment on Heroku.
Test Type      : Functional

Title          : Successful stakeholder login with valid credentials
Requirement    : 3.2 (Stakeholder login)
