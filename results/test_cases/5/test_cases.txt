TC-ID          : TC-5.1-001
Title          : Verify system response time for adding a new speciality
Requirement    : Req-5.1 (Performance Requirements)
Preconditions  :
- User is authenticated with a role that permits adding specialities.
- System is in normal operational state.
- No pending background jobs that could affect performance.
Test Steps     :
  1. Navigate to the "Add Speciality" page.
  2. Enter a valid speciality name "Cardiology".
  3. Submit the form.
  4. Measure the elapsed time from submission to confirmation display.
Expected Result: The speciality is created and a confirmation message appears within 2 seconds of submission.
Test Type      : Performance
