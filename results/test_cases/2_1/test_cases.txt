TC-ID          : TC-2.1-001
Title          : Submit consultation request with valid symptoms
Requirement    : REQ-2.1-001 (Patient can create a consultation request by entering symptoms)
Preconditions  : • Patient is registered and logged into the system.
                  • System is online.
Test Steps     :
  1. Navigate to the “New Consultation” page.
  2. Enter a non‑empty symptom description (e.g., “persistent cough and fever”).
  3. Click the “Submit” button.
Expected Result: The system records the consultation request, displays a confirmation message, and forwards the request to a doctor of the appropriate speciality.
Test Type      : Functional
---
TC-ID          : TC-2.1-002
Title          : System forwards consultation request to appropriate doctor
Requirement    : REQ-2.1-002 (System must route request to a doctor with matching speciality)
Preconditions  : • Consultation request from TC‑2.1‑001 exists.
                  • At least one doctor with the required speciality is active in the system.
Test Steps     :
  1. Log in as the doctor of the matching speciality.
  2. Access the “Pending Consultations” list.
Expected Result: The newly submitted consultation request appears in the doctor’s pending list with correct patient symptoms.
Test Type      : Functional

TC-ID          : TC-2.1-003
Title          : Doctor generates a complete prescription
Requirement    : REQ-2.1-003 (Doctor can create a prescription containing Diagnosis, Medicines, and optional Lab Requests)
Preconditions  : • Doctor is logged in and has the pending consultation from TC‑2.1‑001.
Test Steps     :
  1. Open the pending consultation.
  2. Enter a diagnosis (e.g., “Upper respiratory infection”).
  3. Add at least one medicine (e.g., “Amoxicillin 500 mg – 3 times/day for 7 days”).
  4. Add a lab request (e.g., “Complete blood count”) if needed.
  5. Click “Generate Prescription”.
Expected Result: The prescription is saved, assigned a unique ID, and is dispatched to the patient, the nearest chemist, and the nearest lab.
Test Type      : Functional

TC-ID          : TC-2.1-017
Title          : Unauthorized user attempts to access a patient’s prescription
Requirement    : REQ-2.1‑004 / REQ-2.1‑005 / REQ-2.1‑006 (Access control)
Preconditions  : • An unauthenticated user (not logged in) or a logged‑in user with a different role tries to access a prescription URL.

  1. Directly enter the URL of the patient’s prescription in the browser.
  2. Press Enter.
Expected Result: The system redirects to the login page or shows “Access Denied”; no prescription data is disclosed.
