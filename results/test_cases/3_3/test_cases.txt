TC-ID          : TC-3.3-001
Title          : Verify chemist can log in and view prescriptions
Requirement    : Req-3.3-1 (Self‑contained system, role‑based login)
Preconditions  : • Chemist user account exists with valid credentials  
                 • System is deployed and accessible via supported browser
Test Steps     :
  1. Open the system URL in Google Chrome.
  2. Enter chemist’s username and password.
  3. Click the **Login** button.
  4. Navigate to the “Prescriptions” dashboard.
Expected Result: Chemist is authenticated, redirected to dashboard, and a list of prescriptions assigned to the chemist is displayed.
Test Type      : Functional

TC-ID          : TC-3.3-009
Title          : Process payment securely via Debit/Credit Card using payment gateway
Requirement    : Req-3.3-3 (Payment gateway integration)
Preconditions  : • Patient is logged in and has a pending prescription invoice  
                 • Payment gateway credentials are configured and reachable
Test Steps     :
  1. Click the **Pay Now** button on the invoice page.
  2. In the payment modal, select “Credit Card”.
  3. Enter valid card details (test card number, expiry, CVV).
  4. Submit the payment.
Expected Result: Payment gateway returns a success response; system marks the invoice as “Paid”, displays a confirmation message, and enables the “Send Invoice” button.
Test Type      : Functional
