Title          : Add new medical specialty to specialty database (happy path)
Requirement    : R1
Preconditions  : • Admin user is logged in with “Admin” role  
                • Specialty database is accessible
Test Steps     :
  1. Navigate to “Admin → Manage Specialties”.
  2. Click “Add Specialty”.
  3. Enter a unique specialty name “Dermatology”.
