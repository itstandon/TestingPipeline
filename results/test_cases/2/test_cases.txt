TC-ID          : TC-2-001
Title          : Add a new doctor with valid details
Requirement    : Req-2.1 (Maintain Doctors)
Preconditions  : • Tester is logged in as an Administrator role.
                • Doctor management screen is open.
Test Steps     :
  1. Click the “Add Doctor” button.
  2. Enter a unique Doctor ID, full name, specialty, contact number, and email in the required fields.
  3. Click “Save”.
Expected Result: The system stores the new doctor record, displays a confirmation message “Doctor added successfully”, and the doctor appears in the doctors list.
Test Type      : Functional
