**TC-ID**          : TC‑REG‑001  
**Title**          : Successful Patient Registration (Happy Path)  
**Workflow**       : Patient Registration → Consultation Request → Prescription Delivery  
**Requirements**   : Req‑5/1, Req‑5/2, UC‑01, BR‑6, BR‑2  
**Preconditions**  :  
  - Admin has already created the default admin account and logged in.  
  - System is up and running (URL reachable via HTTPS).  
**Test Steps**     :  
  1. Open the Virtual Clinic website in Chrome.  
  2. Click **“Register”** and fill all mandatory fields (Name, DOB, Gender, Address with a valid Pin‑code, Email, Phone, Password).  
  3. Click **“Submit”.**  
  4. Verify that a confirmation message “Registration successful. Your Patient‑ID is XXXXX” appears.  
  5. Log in using the newly created credentials.  
**Expected Result**: Patient account is created, unique Patient‑ID generated, and the user lands on the Patient Dashboard within 4 seconds.  
**Test Type**      : Functional
