TC-ID          : TC-5.1-001
Title          : Verify system scales to 10,000 concurrent patient users (happy path)
Requirement    : Req-5.1-Scaling
Preconditions  :
  - Load‑testing framework (e.g., JMeter) is installed and configured.
  - Production‑like environment is running with all services started.
  - Monitoring and logging are active.
Test Steps     :
  1. Configure the load generator to create 10,000 simultaneous patient sessions.
  2. Each session performs a realistic workflow: login → view profile → request consultation.
  3. Run the load for 5 minutes while capturing CPU, memory, network, and response‑time metrics.
  4. After the run, collect error logs and aggregate response‑time statistics.
Expected Result: System remains operational, error rate ≤ 0.1 %, average response times stay within the SLAs defined in Req‑5.1‑RT‑*. No service crashes or resource exhaustion observed.
Test Type      : Performance

TC-ID          : TC-5.1-002
Title          : Verify system behavior at exact scaling boundary of 10,000 users
Requirement    : Req-5.1-Scaling
Preconditions  :
  - Same as TC‑5.1‑001.
Test Steps     :
  1. Generate exactly 10,000 concurrent sessions as in TC‑5.1‑001.
