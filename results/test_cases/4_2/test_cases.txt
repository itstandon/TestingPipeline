TC-ID          : TC-4.2-001
Title          : Add a new unique Speciality (Happy Path)
Requirement    : Req-1/1
Preconditions  :
  - Administrator is logged in with valid credentials.
  - No existing Speciality with name “Cardiology”.
Test Steps     :
  1. Navigate to **Maintain Specialities** → **Add Speciality** screen.
  2. Enter “Cardiology” as the Speciality name and fill required fields.
  3. Click **Save**.
Expected Result: The system stores the new Speciality “Cardiology”, displays a success message, and the Speciality appears in the Specialities list.
Test Type      : Functional
