TC-ID          : TC-4.1-001
Title          : Create Doctor user with valid data
Requirement    : VCSYSS02-1
Preconditions  :
- Administrator is logged into the system with valid admin credentials.
- Administrator is on the “Create User” screen.
Test Steps     :
  1. Select role “Doctor” from the role dropdown.
  2. Enter a unique username (e.g., dr.johnsmith).
  3. Enter a valid email address (dr.john@example.com).
  4. Enter a password that meets policy (e.g., Passw0rd!).
  5. Fill required doctor‑specific fields (License Number: 1234567890, Specialty: Cardiology).
  6. Click the “Create” button.
Expected Result: The system displays a success message “User created successfully”, the new doctor appears in the user list, and an audit log entry is recorded.
Test Type      : Functional
