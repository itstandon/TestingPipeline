TC-ID          : TC-5.2-001
Title          : Generate regulatory compliance report (happy path)
Requirement    : REQ-5.2-001
Preconditions  :
- System is configured with current Government of India health‑care regulation rules.
- Test user has the “Compliance Analyst” role.
- Sufficient patient and operational data exist in the database.
Test Steps     :
  1. Log in to the system as the Compliance Analyst.
  2. Navigate to the “Compliance” module.
  3. Select “Generate Full Compliance Report”.
  4. Click the “Generate” button.
Expected Result: The system produces a PDF/HTML report that includes all required regulatory sections, data integrity checks, and audit‑log summaries without errors.
Test Type      : Functional

TC-ID          : TC-5.2-009
Title          : Enforce newly mandated regulatory field during data entry (functional)
Requirement    : REQ-5.2-001
Preconditions  :
- Government of India has issued an amendment requiring the field “ConsentObtainedDate” for every patient record.
- System is updated with the new mandatory field rule.
- Test user has “Clinician” role.
Test Steps     :
  1. Log in as Clinician.
  2. Open “Create New Patient Record” form.
  3. Fill all required fields **except** “ConsentObtainedDate”.
  4. Attempt to save the record.
Expected Result: System blocks the save operation and displays “Error: ‘ConsentObtainedDate’ is required per regulatory amendment.”
Test Type      : Negative
